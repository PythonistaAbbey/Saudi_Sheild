Implementation stages

Four gated stages, each needing a decision to continue

1 · 8–12 weeks

Discovery with the authority

Confirm scope, feed format, keys, templates, languages and hosting. Data protection impact assessment.

2 · 4–6 months

Pilot integration

Connect to a test CAP feed, apply NCA controls, native builds, security testing, joint drills.

3 · 3–6 months

Limited pilot

One region and selected languages, during drills only. Usability testing with residents, including people with disabilities.

4 · Subject to approval

National rollout

Only after evaluation and formal approval. Cell broadcast and sirens remain the authoritative channel throughout.

Each gate has exit criteria agreed with the authority. Stopping after any stage leaves nothing running in public.

Roadmap: docs/04-roadmap.md

The prototype is stage zero. The ask today is only to start stage one, a discovery phase with no public exposure. Nothing goes live without the authority's explicit decision at each gate.
