Positioning

A companion channel with firm limits

What it does

  • Republishes alerts signed by an authorised issuer, after human review
  • Keeps a verified history and a clear “danger has ended” status
  • Arabic and English now; more languages from approved templates
  • Read-aloud, plain words, large text, offline guidance
  • Voluntary family “I’m safe” check-ins without location

What it will never do

  • Originate, declare or escalate a warning by itself
  • Replace cell broadcast or sirens, which stay authoritative
  • Track, predict or locate any missile or drone threat
  • Let AI issue instructions or evacuation orders
  • Look like an official government service

Safety boundaries are enforced in code and tests (docs/05-safety-boundaries.md).

The right-hand column is as important as the left. In the prototype these limits are enforced: the data model has no fields for threat tracks or impact points, payloads containing such fields are discarded, and the code refuses any message that is not marked as an exercise.
