Civilian app

Calm, verified and readable under stress

  • Every alert shows its level, area, time and a verified badge
  • Up to five plain steps, read aloud on request
  • Arabic and English, right to left, large text, high contrast
  • A lite feed of 1.2 KB for slow networks; offline guidance
  • A purple exercise ribbon on every simulated screen

Expo / React Native, shown as the web build · Screenshots from the automated journey (docs/screenshots)

One code base for iOS, Android and web. The app verifies each alert with a pinned publisher key before showing it. If verification fails it shows nothing new and keeps the last verified state. The all-clear is a first-class screen because people need to know when danger has ended.
