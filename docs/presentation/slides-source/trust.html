Trust and integrity

Fake or altered messages never reach the public

Signed twice. The issuer signs the message; the platform signs the public feed; the app checks both with a pinned key.

Quarantine, not silence. Bad signatures, unknown or revoked keys and forbidden fields are held for review with a reason.

Tamper-evident log. Each audit entry is hash-chained to the last, so an edited record breaks the chain.

Exercise only. The prototype refuses any message not marked as an exercise.

Ed25519 over canonical JSON · Demo keys only; production keys would live in an HSM
